# Codex Proxy 账号指纹巡检

`cpr-iq-test` 是 `codex-proxy-rs` 的独立插件。它通过宿主的模型回调，使用**指定的 OpenAI OAuth 账号**完成探针，再在本地比较 `lm-detector` 参考指纹。不读 OAuth Token 或 Client Key 明文，不改账号、路由或宿主源码。

**当前是开发预览。** 首个宿主目标是 `v3.54.5`（`45a4d580c7e1ac2b2c0308d72ae5018148f2516a`）。`gpt-6-sol / low` 目前只开放**校准（仅排名）**：没有授权正常账号的实测证据前，正式判定、定时巡检和生产发布保持关闭。开发包不占用将来的正式版本号。

## 安装与操作

1. 确认宿主版本和平台与验证记录一致，并核对 `.tar.gz` 的 SHA-256。通过宿主的 **插件 → 上传并校验** 安装包、确认信任、启用实例。插件运行在宿主的 `trustedProcess` 模式，并非沙箱；仅安装来自可信发布者的包。
2. 打开 **账号指纹巡检**。挑选一个其权限涵盖目标账号和模型的测试 Client Key、一个模型档位，以及 1–10 个启用的 OpenAI OAuth 账号。插件只使用 Key ID；**调用可能消耗该 Key 的额度**。建议用单独、限额较低的测试 Key，且不要为它设置模型别名或改写推理参数。
3. 加入队列后，由宿主的维护任务执行，不需要保留页面。每个账号首轮 3 次调用，正式判定必要时再用 3 个新探针复测；校准从不自动复测。若指定账号不可用，不切换到别的账号。
4. 正式档位开放后，可单独设置巡检目标和 24 小时、48 小时、7 天间隔。初始关闭，首次启用从保存后一个周期开始。每实例串行，滚动 24 小时共享预算默认 60 次（可降到 3 次）；超额跳过，不补跑旧的时间槽。停用不会再次发送已发出的请求，也不会发起后续轮或待处理的巡检。

| 结论 | 含义 |
| --- | --- |
| 未发现指纹异常 | 三份完整回复可评分，目标参考标签排名第一，且达到该档位已验证的排名差要求。 |
| 疑似指纹不符 | 两轮均有三份可评分的完整样本，目标均不在前三，而且第一名是同一个非目标标签。 |
| 证据不足 | 样本不全、评分未校准、候选相近、档位不受支持、期间版本改变或复测不一致。 |
| 检测失败 / 中断 / 跳过 | 权限、账号状态、限流、超时、重启或预算等问题。不能据此判断指纹。 |

排名只表示与**该版本参考库**的相似程度，不是身份认证，不能检测同一模型内部的推理能力变化。“未发现”不等同于“没有降智”。参考库的合并标签原样展示。结果不自动影响路由；宿主既有权限、限流、计费、账号保护仍然生效。

## 构建开发包

需要 Git、Rust `1.99.1` 和 Python 3.12+。首次构建时下载并校验两份锁定数据，之后可用 `--offline` 复用本地文件。插件启动和评分不会访问第三方检测服务。

```bash
# 在本项目根目录执行。不要用未锁定的上游 main 打生产包。
mkdir -p .work
git clone --depth 1 --branch v3.54.5 https://github.com/zyycn/codex-proxy-rs.git .work/host-source
python3 scripts/detector_assets.py
CPR_REQUIRE_BANK=1 cargo test --locked --all-targets
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/package.py \
  --host-source .work/host-source --host-tag v3.54.5 \
  --host-sha 45a4d580c7e1ac2b2c0308d72ae5018148f2516a \
  --target aarch64-apple-darwin --version 0.1.0-dev.1 --offline
```

该命令调用指定宿主提交的 `cpr-plugin`，将本平台安装包和校验文件写入 `dist/`。Linux 使用本机相应的平台：`x86_64-unknown-linux-gnu` 或 `aarch64-unknown-linux-gnu`。一致性测试和状态切换操作见 [验证与发版](docs/release.md)。

## 实现边界

- `src/host.rs` 封装宿主回调、账号绑定和事件解析；`src/service.rs` 接入管理与维护。只声明 `management v2` 和 `maintenance v1`。
- `src/fingerprint.rs` 使用 `lmfpd` 生成探针并离线评分。数据锁与宿主版本独立，任何一个资源 SHA-256 不匹配都不发送探针。更换检测数据、模型或档位会令旧实测记录失效。
- `src/domain.rs` 不把队列、预算和历史拆成多个事务。先以宿主私有状态 CAS 认领和预留三次调用，再发送；如果认领存在但结果未知，记为中断，不重发。同一轮先保守预留额度，可能未用满，但不会因超时或崩溃重复扣预算。保存最近 100 条、最长 30 天的摘要，不保存原始回复、探针文本或凭据。
- `.github/workflows/follow-host.yml` 每 30 分钟检查最新正式版，也可手动指定稳定 tag 补验中间版本。通过三平台旧包验收只写兼容表；需要才重建。夜间 `main` 流程只预警，不发布。**CI 无生产凭据，不自动安装或切换生产实例。**
