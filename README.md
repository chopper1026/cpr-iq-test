# Codex Proxy 账号指纹巡检

`cpr-iq-test` 是 `codex-proxy-rs` 的独立原生插件。它通过宿主的模型回调，使用**指定的 OpenAI OAuth 账号**发送离线生成的探针，并在本地与 `lm-detector` 参考指纹库比对。插件不读取 OAuth Token 或 Client Key 明文，不修改账号状态、路由或宿主源码。

首个适配宿主为 `v3.54.5`（`45a4d580c7e1ac2b2c0308d72ae5018148f2516a`）。

## 安装与操作

1. 确认宿主版本与目标平台一致并核对 `.tar.gz` 的 SHA-256。在宿主 **插件 → 上传并校验** 中安装包、确认信任并启用实例。插件运行在宿主的 `trustedProcess` 模式，并非沙箱；仅安装可信发布者的包。
2. 打开 **账号指纹巡检** 管理页，在 **检测与巡检** Tab 页中：
   - **自动获取模型与推理档位**：插件自动读取宿主原生 Codex 模型目录（及当前 Key 可见模型），展示全部可用模型及各自支持的推理强度（如 `low` / `medium` / `high` / `xhigh` / `max` 或不指定推理强度），点击右上角 **刷新目录** 可立即刷新。
   - **真实账号邮箱展示**：指定账号列表优先显示账号真实邮箱（辅助展示自定义名称、订阅套餐与账号 ID），支持按邮箱/名称/ID 搜索及批量全选。
   - **手动检测**：选择测试 Client Key、模型、推理档位和 1–100 个启用的 OpenAI OAuth 账号，点击 **开始检测** 加入队列。调用按所选 Client Key 规则计费，建议选用独立测试 Key 且避免模型重写或推理参数覆盖。
   - **定时巡检**：默认关闭，支持按 `1 / 6 / 12 / 24 / 48 小时` 或 `7 天` 周期自动检测指定账号；错过周期不补跑积压任务，停用或变更计划会跳过未执行的旧定时任务。
3. 切换到独立的 **任务记录** Tab 页查看执行中、排队中与历史检测记录：
   - 支持快捷状态统计标签、关键字搜索（邮箱 / 账号 ID / 任务 ID / 模型 / 候选标签）、来源筛选（手动 / 定时）、状态筛选、模型与推理档位筛选、取消待执行排队任务，以及服务端分页（10 / 20 / 50 条每页）。
   - 支持单条任务「日志」查看与全局/筛选范围的 **导出诊断日志**（JSON / 纯文本诊断摘要、一键复制，含阶段耗时、凭据版本变化、逐探针批次/事件/字符/结束原因与运行期事件日志，不含任何凭据明文或原始对话正文）。
4. 任务由宿主维护回调串行执行，无需保持页面打开。每账号首轮发送 3 次独立探针；对参考库中已收录的模型，若首轮目标掉出前三则自动用 3 个新探针复测确认。指定账号不可用时绝不回落到其他账号。

| 结论 | 含义 |
| --- | --- |
| 指纹匹配 | 被测模型在参考库内，三份完整回复可评分，目标参考标签排名第一且具有正向差距。 |
| 参考排名 | 被测模型暂未收录于当前参考库，给出 Top-3 最接近参考模型及概率分布，不强行判错。 |
| 疑似指纹异常 | 被测模型在参考库内，两轮独立检测均完整可评分、目标均不在前三，且第一名为同一个非目标标签。 |
| 证据不足 | 样本不全、有效数字不足、目标名次接近、两轮复测不一致、回复被中间件改写或采样期间上游账号身份被替换。 |
| 检测失败 / 已中断 / 已跳过 | 权限、账号状态、限流、超时、重启中断或巡检计划变更等运行期问题，不能据此判断指纹。 |

参考排名反映的是与**当前锁定版本参考库**的统计相似度，并非身份认证，也不自动修改账号状态或路由；宿主既有权限、限流、计费与账号保护规则继续生效。

## 构建开发包

需要 Git、Rust `1.99.1` 和 Python 3.12+。首次构建会下载并按 `data/detector.lock.json` 校验两份锁定数据，之后可追加 `--offline` 复用本地文件。插件运行时与离线评分不访问第三方检测服务。

```bash
mkdir -p .work
git clone --depth 1 --branch v3.54.5 https://github.com/zyycn/codex-proxy-rs.git .work/host-source
python3 scripts/detector_assets.py
CPR_REQUIRE_BANK=1 cargo test --locked --all-targets
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/package.py \
  --host-source .work/host-source --host-tag v3.54.5 \
  --host-sha 45a4d580c7e1ac2b2c0308d72ae5018148f2516a \
  --target aarch64-apple-darwin --version 0.1.0-dev.2 --offline
```

该命令调用指定宿主提交的 `cpr-plugin`，将本平台安装包与 `.sha256` 写入 `dist/`。Linux 对应平台为 `x86_64-unknown-linux-gnu` 或 `aarch64-unknown-linux-gnu`。隔离验证、跟版流程与回滚见 [验证、跟版与回滚](docs/release.md)。

## 实现边界

- `src/host.rs` 封装宿主回调、邮箱优先账号目录、原生模型与推理档位发现、绑定账号 Responses 流解析（支持推理模型稀疏 `content_index`）及私有状态 CAS；`src/service.rs` 提供管理路由（含服务端筛选分页与待执行取消）及维护调度。清单仅声明 `management v2` 和 `maintenance v1`。
- `src/fingerprint.rs` 使用 `lmfpd` 生成探针并离线评分，支持参考库全量 76 个模型及合并标签别名匹配；数据锁任意文件 SHA-256 不匹配时不发送探针。
- `src/domain.rs` 以单份宿主私有状态文档原子保存定时计划、队列与最近 30 天（最多 500 条）摘要历史，并兼容迁移 `v0.1.0-dev.1` 历史记录与设置。不保存探针正文、原始回复、OAuth Token 或 Client Key 明文；配额与切换影响见 [持久化与备份边界](docs/development/PERSISTENCE.md)。
- `.github/workflows/follow-host.yml` 负责宿主版本与契约跟版、三平台构建与隔离宿主 smoke、`prerelease` 预览与发布闸门；**CI 无生产凭据，不自动安装或切换生产实例。**
